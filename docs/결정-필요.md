## G. 근거 문서끼리 맞출 것 (insta-toon-project)

- **확인 횟수**: 사이트는 "고르기 1 + 확인 2(콘티·완성본, 2화씩)"로 맞췄다. 영업 흐름·덱 문서의 횟수를 이것과 맞춘다.
- **블로그용 이미지**: GTM 문서는 "사연 하나를 툰·정보툰·릴스·블로그용 이미지로 펼친다"고 하지만 상품표에는 없다. 사이트에는 "완성본을 블로그에도 쓸 수 있다"(권리)만 적었다.
- **FAQ "그림은 어떻게 만드나요"**: 영업 흐름 8장의 답도 "콘티 초안과 그림에 AI 도구를 쓰고, 사실관계·대사·컷 선택은 사람이"로 고친다.
- **견본 라벨**: 견본 표지 이미지 안에 "실제 사례 각색" 라벨이 찍혀 있다면 "창작툰" 라벨로 다시 렌더해야 한다 (saga.yaml 규칙).

### H-2. 인스타툰을 서비스 하나로 분리 (2026-10-15, 정현 결정 "A안")

- 홈(`/`): 히어로 → 왜 설명인가 → **서비스 카드 4장** → 견본 맛보기 → 만드는 사람 → 같이 풀고 싶은 병목 → 마무리(일반 단계)
- 인스타툰 상세는 **`/services/instatoon`** 으로 옮김: 쓰임새, 3단계, 장점, 처음부터 끝까지, 분야별 소재, 가격, FAQ, 시안·연재 단계. **콜드 세일즈 메일의 링크는 이 주소로.**
- 서비스 카드 상태 표기: 인스타툰 연재 "운영 중 · 가격 공개" / 고객 안내 콘텐츠·문의·상담 응대 설계 "상담 후 맞춤 제작" / 반복 서류 정리 "함께 만드는 중". 인스타툰 말고는 판 적이 없으니 운영 중처럼 쓰지 않는다.
- 머리말 버튼 "가격 보기" → "서비스 보기"(`/#services`).
- 확인할 점: 맞춤 제작 두 장을 미팅에서 물어보면 무엇을 보여 줄지(견본이 아직 없음).
